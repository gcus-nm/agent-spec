# MCPとVOICEVOX

## MCP

- Unity操作・実装: uLoopMCP。Unityコード変更後はコンパイルとログを確認します。
- リポジトリ文書・コード構造・メモリ: Serena。
- ブラウザ操作、スクレイピング、E2E: Playwright。
- 公開API、ライブラリ、SDK、CLIの最新仕様: Context7。
- GitHubのPR、Issue、レビュー、チェック: GitHub MCPまたはコネクター。
- ローカルファイルの探索・読取・操作: File System。
- 必要なMCPが未設定または権限不足なら、その事実と影響を報告します。

## VOICEVOX

- `speaker=29`、`speedScale=1.1` を使用します。
- 英単語は自然なカタカナへ変換し、不要なスペースを削除します。
- 1回100文字以内で、次のタイミングに簡潔に通知します。
  - 受領: 「了解です」または「承知しました」
  - 開始: 「〜を開始します」
  - 作業中: 思考内容・実行中・実行予定を20文字程度
  - 進捗: 「半分完了です」「もう少しです」
  - 重要なお知らせ、エラー
  - 完了: 出力要旨を30文字程度にまとめ、「完了です」または「修正完了です」を含める
- 全タスク完了時に音声通知を試みます。
- エンジンへ接続できない場合は作業を不必要に止めず、失敗をテキストで報告します。

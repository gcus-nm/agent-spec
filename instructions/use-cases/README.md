# ユースケース別指示の索引

依頼種別を判定したら、次の対応表から該当する文書を読みます。複数の種別を含む依頼では、
必要な文書を組み合わせます。

| 依頼種別 | 読む文書 |
|---|---|
| コード、設定、テスト、ビルド、データなどの変更・実装 | [`code-change.md`](code-change.md) |
| コード、差分、PRのレビュー | [`code-review.md`](code-review.md) |
| 仕様、外部情報、原因、選択肢の調査 | [`research.md`](research.md) |

単なる質問に変更手順を適用したり、変更依頼を調査だけで止めたりしません。ルート指示、
汎用タスクライフサイクル、プロジェクト固有指示を優先し、この索引は該当する詳細手順を
選ぶために使います。

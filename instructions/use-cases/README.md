# ユースケース別指示のフォールバック索引

環境ルートまたはプロジェクト `AGENTS.md` に直接ルートがない特殊作業だけ、この索引を読みます。
頻出タスクは入口から対象文書へ直接進み、本索引を中継しません。

| 依頼種別 | 読む文書 |
|---|---|
| 大規模なコード、設定、テスト、ビルド、データの変更 | [`code-change.md`](code-change.md) |
| コード、差分、PRのレビュー | [`code-review.md`](code-review.md) |
| 複雑な仕様、外部情報、原因、選択肢の調査 | [`research.md`](research.md) |

複数の種別を含む場合も、必要な文書だけを組み合わせます。単純な質問や小規模修正へ詳細ガイドを
追加しません。
